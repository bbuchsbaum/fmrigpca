# fmrigpca: Design-free fMRI Dimensionality Reduction with Generalized PCA

Tools to build row/column metrics for generalized PCA (genpca) on fMRI
data using NeuroVec/NeuroVol (neuroim2). Includes spatial graph
Laplacian builders, tissue/tSNR-informed voxel or parcel metrics (A),
temporal AR(p) whitener and frame-weighted row metrics (M),
batch-friendly fitting across runs, and rank selection & stability
utilities. Works with NeuroVec (voxel) and ClusteredNeuroVec (parcel).
